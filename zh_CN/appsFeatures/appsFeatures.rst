.. _appsFeatures:

#########################
应用与功能
#########################

本节涵盖 Red Pitaya 板卡的各种使用、控制和编程方式，从简单的 Web 应用到高级多板同步和自定义编程。
更多资源请参阅 :ref:`开发者指南 <developer_guide>`。

**本节内容：**

* **数据采集与发生简介** - 从简单应用到高级流传输和 FPGA 定制的全部方法概览
* **应用** - 示波器、频谱分析仪、Bode 分析仪、流传输和社区应用指南
* **系统工具** - 网络配置、OS 更新、校准和系统信息管理
* **多板同步** - 使用 Click Shield 或 X-Channel 配置创建多通道系统
* **编程与远程控制** - SCPI 命令、Python/C++ API、MATLAB、LabVIEW、JupyterLab 和深度存储器模式
* **命令行工具** - 用于脚本和自动化的终端工具
* **按型号划分的支持功能** - 不同 Red Pitaya 板卡型号的兼容性信息
