************************************************************************
PyRPL（Leonhard Neuhaus 开发的锁相放大器、数字滤波器等工具）
************************************************************************

PyRPL 是一个开源软件包，在 Red Pitaya 平台板卡上提供多种仪器，例如示波器、网络分析仪、锁相放大器、多种自动反馈控制器和数字滤波器等。PyRPL 已被全球许多研究团队使用，并配有图形界面和易用的 Python API。
