************************************************************************
Linien——易用的激光锁定工具（洪堡大学）
************************************************************************

Linien 使用 RedPitaya（STEMlab 125-14）提供简单可靠的激光锁定。Linien 遵循 UNIX 哲学，专注于做好一件事：使用智能算法进行锁定。
它主要用于锁定光谱信号，也可用于 Pound-Drever-Hall 或其他锁相技术，以及简单的 PID 操作。Linien 使用 Python 和 Migen 构建，并基于 red pid。
