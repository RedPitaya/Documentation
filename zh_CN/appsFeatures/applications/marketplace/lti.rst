*****************
LTI DSP 工作台
*****************

此应用可对物理系统建模，将 Red Pitaya 板卡变成几乎任何可纳入测量和控制电路的线性系统。物理系统通过使用 Red Pitaya 板卡模拟系统的 H(z) 传递函数来建模。应用中预定义了一些 H(z) 函数，可帮助你描述或模拟目标系统。通过应用的 Web 界面可以快速更改 H(z) 传递函数的参数。
