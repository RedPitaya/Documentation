=========
示例
=========

下面列出了通过 SCPI 命令以及板载 C 和 Python API 命令远程控制 Red Pitaya 的示例。JupyterLab 也属于第二类。
这些示例涵盖 Red Pitaya 的所有基本功能，包括：

    * 信号生成。
    * 信号采集。
    * 深存储器采集。
    * 数字 I/O 控制。
    * 通信协议。

您可以根据需要编辑和修改这些示例，开发自定义程序和例程。
