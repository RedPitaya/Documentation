.. _s_rate_and_dec:

采样率与抽取
#############################

下表给出了抽取值示例及其对应的缓冲区时间尺度。


.. note::

    下表仅列出少量抽取示例；实际使用时，用户可以使用以下抽取值：

    **SCPI 命令：**

    - OS 2.00-30 及以上版本：[1, 2, 4, 8, 16, 17, 18, ..., 65535, 65536] - *（不超过 16 的 2 的幂，之后可取不超过 65536 的任意整数）* - **ACQ:DEC:Factor**
    - OS 2.00-23 及以下版本：[1, 2, 4, 8, 16, 64, 256, ..., 32768, 65536] - *（不超过 65536 的 2 的幂）* - **ACQ:DEC**

    **API 命令：**

    - OS 2.00-23 及以上版本：[1, 2, 4, 8, 16, 17, 18, ..., 65535, 65536] - *（不超过 16 的 2 的幂，之后可取不超过 65536 的任意整数）* - **rp_AcqSetDecimationFactor**

|
