#################################
步骤 5：硬件连接
#################################

本节将检查 Red Pitaya 板卡的硬件连接，以确定信号接收或检测是否存在问题。

.. contents:: 目录
    :local:
    :depth: 2
    :backlinks: top

|

适用条件
===============

以下情况请使用本节：

* **可以访问 Web 界面，但接收不到信号**。你可以访问 Web 界面，应用程序也正常工作，但 Red Pitaya 的输入或输出端没有收到任何信号。
  
最可能的原因是硬件连接存在问题。

|

逐步排查硬件问题
=====================================

#.  **输入跳线**。检查 :ref:`输入跳线 <jumper_pos>`。跳线有时会接触不良，需要拔下后重新插入。如果跳线松动或缺失，请予以更换。
#.  **SMA 线缆**。确认 SMA 线缆没有损坏、接触不良或松动。
#.  **T 形连接器和 50 Ω 终端器**。如果使用 T 形连接器和 50 Ω 终端器，请检查其连接是否正确以及是否损坏。
  
    .. note::

        SMA 线缆、T 形连接器、终端器及其他线缆属于消耗品，可能随时间推移而磨损。如果信号接收存在问题，请测试这些部件或更换新品。

#.  **其他线缆和连接**。确认系统的信号连接和供电情况。激光系统镜片未对准、探头连接不正确或组件未供电，有时都会导致接收不到信号。
#.  **校准设置**。错误的校准会使 Red Pitaya 显示不正确的测量结果，甚至看起来完全检测不到信号。这同时适用于 Red Pitaya 的输入和输出。检查 Web 界面中的 :ref:`校准设置 <calibration_app>`，将其重置为 **默认值**，并在必要时重新校准板卡。这会把用户校准更新为最新格式，通常能够解决 Web 界面不显示信号的问题。
