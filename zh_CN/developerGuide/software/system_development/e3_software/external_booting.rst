#################################
从外部存储设备启动
#################################

Red Pitaya GEN2 板卡支持从通过 E3 连接器连接的外部存储设备启动。支持的外部存储选项包括 QSPI 闪存和 eMMC 模块。

这些存储芯片应位于外部模块上（例如 :ref:`E3 扩展板 <E3_HW>`）。

对于自定义启动配置，请使用 AMD (Xilinx) 工具和文档在外部存储设备上设置启动镜像。

.. note::

    有关从外部存储设备启动 Red Pitaya 板卡的更多信息，将在未来的文档更新中提供。
