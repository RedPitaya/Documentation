#####################################################################
使用绘图、增益和偏移从慢速输入读取模拟电压
#####################################################################

本示例通过添加信号调理控件扩展电压绘图应用。你将学习如何对模拟测量应用增益和偏移调整，
从而缩放和移动信号，以便更好地进行可视化和分析。

.. contents:: 目录
    :local:
    :depth: 1
    :backlinks: top

概述
=========

此应用在电压绘图示例中添加增益和偏移控件，演示如何在后端将 UI 参数应用于信号处理。

**核心概念：**

* 使用增益和偏移进行信号调理
* 实时参数更新对信号处理的影响
* 缩放信号以改善可视化效果
* 传输前在后端处理信号

**硬件：**

 :ref:`E2 扩展连接器 <E2_orig_gen>` 上的四个慢速模拟输入引脚（AI0-AI3）中的任意一个都可用于电压测量。

理解增益和偏移
-------------------------------

**增益：**

* 乘以信号幅度
* 适用于放大小信号
* 公式：``Output = Input × Gain``
* 范围：1 至 100（放大 1x 至 100x）

**偏移：**

* 向信号添加恒定电压
* 向上或向下移动信号
* 公式：``Output = Input + Offset``
* 范围：0V 至 5V

**组合公式：**

.. code-block:: none

    Output = (Input × Gain) + Offset

|

实现前端
===========================

HTML 结构
---------------

将增益和偏移控制块添加到 ``index.html`` 中：

**增益控件：**

.. code-block:: html

    <div id='gain_setup'>
        <div>Gain: </div>
        <input id='gain_set' type="range" size="2" value="1" min="1" max="100">
    </div>

* 范围：1 至 100（放大 1x 至 100x）
* 默认值：1（不放大）
* 整数值

**偏移控件：**

.. code-block:: html

    <div id='offset_setup'>
        <div>Offset: </div>
        <input id='offset_set' type="range" size="2" value="0" min="0" max="5" step="0.1">
    </div>

* 范围：0V 至 5V
* 默认值：0V（无偏移）
* 步进：精度为 0.1V

JavaScript 实现
--------------------------

设置增益
^^^^^^^^^^^^^

将 **APP.setGain()** 函数添加到 ``app.js`` 中：

.. code-block:: javascript

    APP.setGain = function() {
        APP.gain = $('#gain_set').val();
        var local = {};
        local['GAIN'] = { value: APP.gain };
        APP.ws.send(JSON.stringify({ parameters: local }));
        $('#gain_value').text(APP.gain);
    };

连接到增益滑块：

.. code-block:: javascript

    $('#gain_set').on('input', function() {
        APP.setGain();
    });

设置偏移
^^^^^^^^^^^^^^^

将 **APP.setOffset()** 函数添加到 ``app.js`` 中：

.. code-block:: javascript

    APP.setOffset = function() {
        APP.offset = $('#offset_set').val();
        var local = {};
        local['OFFSET'] = { value: APP.offset };
        APP.ws.send(JSON.stringify({ parameters: local }));
        $('#offset_value').text(APP.offset);
    };

连接到偏移滑块：

.. code-block:: javascript

    $('#offset_set').on('input', function() {
        APP.setOffset();
    });

实现后端
==========================

参数声明
-----------------------

在 ``main.cpp`` 中添加两个用于增益和偏移的新参数：

**增益参数：**

.. code-block:: c

    CIntParameter GAIN("GAIN", CBaseParameter::RW, 1, 0, 1, 100);

* 参数名称：“GAIN”
* 访问权限：读/写
* 默认值：1（不放大）
* 最小值：1（1x）
* 最大值：100（100x 放大）

**偏移参数：**

.. code-block:: c

    CFloatParameter OFFSET("OFFSET", CBaseParameter::RW, 0.0, 0, 0.0, 5.0);

* 参数名称：“OFFSET”
* 访问权限：读/写
* 默认值：0.0V（无偏移）
* 最小值：0.0V
* 最大值：5.0V

|

参数更新
------------------

在 **OnNewParams()** 函数中更新参数：

.. code-block:: c

    void OnNewParams(void) {
        GAIN.Update();
        OFFSET.Update();
    }

|

应用信号调理
------------------------------

修改 **UpdateSignals()** 函数，在写入信号时应用增益和偏移：

.. code-block:: c

    void UpdateSignals(void) {
        float val;
        
        // Read voltage from analog input pin 0
        rp_AIpinGetValue(0, &val);
        
        // Remove oldest measurement from buffer
        g_data.erase(g_data.begin());
        
        // Add new measurement to end of buffer
        g_data.push_back(val);
        
        // Write entire buffer to signal with gain and offset applied
        for(int i = 0; i < SIGNAL_SIZE_DEFAULT; i++) 
        {
            VOLTAGE[i] = (g_data[i] * GAIN.Value()) + OFFSET.Value();
        }
    }

**相对于基础绘图示例的主要变化：**

* 原始数据不经修改直接存储在 ``g_data`` 中
* 仅在写入 VOLTAGE 信号时应用增益和偏移
* 这样可以在不丢失原始数据的情况下更改增益/偏移

|

理解信号调理
===================================

为什么使用增益？
--------------------

**问题场景：**

在缩放为 0-3.3 V 的图上，小电压信号（例如 0-0.1 V）很难看清。

**解决方案：**

应用增益放大信号，以获得更好的可视化效果：

* 使用 10x 增益：0-0.1 V 在显示屏上变为 0-1.0 V
* 使用 100x 增益：0-0.1 V 在显示屏上变为 0-10 V（在图形边界处发生裁剪）

**示例：**

.. code-block:: none

    Raw signal: 0.05 V
    With gain = 10: 0.05 V × 10 = 0.5 V (displayed)
    With gain = 50: 0.05 V × 50 = 2.5 V (displayed)

|

为什么使用偏移？
----------------

**问题场景：**

信号在 1.5 V 和 1.6 V 之间变化。在 0-3.3 V 的刻度上，这种变化几乎不可见。

**解决方案：**

应用偏移来移动信号基线：

* 减去 1.5 V 偏移：信号现在看起来在 0 V 至 0.1 V 之间变化
* 与 10x 增益结合：信号在 0 V 至 1.0 V 之间变化（清晰可见）

.. note::
    
    在本示例中，偏移是相加（正值）而不是相减。若要使信号以 0 V 为中心，则需要负偏移功能。

|

组合增益和偏移
--------------------------

**应用顺序很重要：**

本示例应用的公式为：``Output = (Input × Gain) + Offset``

**示例：**

.. code-block:: none

    Raw signal: 0.5 V
    Gain: 2x
    Offset: +0.5 V
    
    Result: (0.5 V × 2) + 0.5 V = 1.5 V

|

带信号调理的数据流
====================================

信号处理流程
---------------------------

1. **读取 AI 引脚** → 原始电压值（例如 0.123 V）
2. **存入缓冲区** → 原始值保存到 g_data 向量
3. **应用增益** → 乘以 GAIN 参数（例如 × 10 = 1.23 V）
4. **应用偏移** → 加上 OFFSET 参数（例如 + 0.5 V = 1.73 V）
5. **写入信号** → 调理后的值存储在 VOLTAGE 数组中
6. **传输** → 信号发送到前端
7. **显示** → 图形显示调理后的电压（1.73V）

|

保留原始数据
--------------------

**重要设计选择：**

原始数据存储在 ``g_data`` 中，不应用增益/偏移。这样可以：

* 在不丢失信息的情况下更改增益/偏移
* 使用新参数重新处理历史数据
* 在需要时准确记录原始数据

|

测试应用
========================

硬件设置
---------------

1. 将电压源连接到一个模拟输入引脚（例如 AI0）
2. 使用变化较小的信号源，以更好地展示增益/偏移效果
3. 推荐使用电位器或低幅度信号发生器

|

应用测试
--------------------

**测试增益功能：**

1. 连接低电压信号（例如 0.1 V）
2. 注意观察它在图上可能难以看清
3. 将增益提高到 10x
4. 确认信号现在清晰可见（显示为 1.0 V）
5. 继续提高增益并观察放大效果

**测试偏移功能：**

1. 连接稳定电压（例如 1.5 V）
2. 注意图上的基线位置
3. 添加 +1.0 V 偏移
4. 确认显示的信号向上移动 1.0 V（显示为 2.5 V）

**测试组合效果：**

1. 从小型 AC 信号开始（例如 1.5 V DC 上叠加 0.05 V 峰峰值）
2. 应用 gain = 20 以放大 AC 分量
3. 应用偏移以移动整个信号
4. 观察放大和移动效果

**监测裁剪：**

* 增益较高时，信号可能超出显示范围
* 高于 3.3 V（或图形 Y 轴最大值）的数值将被裁剪
* 如果发生裁剪，请降低增益或调整偏移

实际应用场景
=====================

放大传感器信号
---------------------------

**场景：** 温度传感器对 0-100°C 输出 0-100mV

**解决方案：**

* 应用 gain = 33，将 0-100 mV 缩放到 0-3.3 V
* 传感器的完整范围现在使用完整显示范围
* 改善可视化效果和分辨率

|

使 AC 信号居中
---------------------

**场景：** AC 信号围绕 1.65 V DC 变化 ±0.1 V

**挑战：** 本示例仅支持正偏移

**解决方法：**

* 使用增益放大 AC 分量
* 偏移仅限于正值
* 若要真正居中，则需要负偏移（功能增强）

|

动态范围调整
-------------------------

**场景：** 信号幅度随时间变化

**解决方案：**

* 信号较小时提高增益
* 信号较大时降低增益
* 手动调整或实现自动量程

|

扩展本示例
=======================

可能的增强
----------------------

* **负偏移** - 支持 -5 V 至 +5 V 的偏移范围，以使信号居中
* **自动缩放** - 自动调整增益，使信号适合显示范围
* **偏移校准** - 添加“归零”按钮，将当前值设为基线
* **增益预设** - 为常用增益值（1x、10x、100x）提供快捷按钮
* **显示单位** - 根据增益转换为工程单位（mV、μV）
* **原始数据视图** - 在原始信号和调理后信号显示之间切换
* **多通道** - 为每个通道独立设置增益/偏移
* **滤波** - 添加低通、高通或带通滤波器
