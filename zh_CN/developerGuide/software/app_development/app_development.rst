#######################
应用程序开发
#######################

本节介绍如何开发在 Red Pitaya 上运行的自定义应用程序。无论是创建测量工具、自动化脚本还是自定义 Web 界面，都可以在这里找到 Red Pitaya API 和开发框架的使用指南。

**本节内容：**

* **C++ 和 Python API** — 用于应用程序开发的原生 API 库，可完整访问硬件
* **流式传输应用程序** — 在 Red Pitaya 与 PC 之间连续高速传输数据
* **Web 应用程序** — 为 Red Pitaya 创建基于浏览器的用户界面
