###############
入门
###############

本节介绍为软件开发访问并连接 Red Pitaya 的基础知识。开发或部署软件之前，需要先建立到 Red Pitaya Linux 操作系统的连接。

**本节内容：**

* **控制台访问** — 通过 SSH 或串口控制台连接 Red Pitaya，获得命令行访问
* **C++ 编译器与 Make** — 安装用于构建 C++ 应用程序的开发工具（Windows 用户）
* **WSL 设置** — 为 Red Pitaya 开发配置适用于 Linux 的 Windows 子系统（Windows 用户）
