软件
########

本节介绍 Red Pitaya 软件开发，从基本的控制台访问到构建自定义应用程序和修改操作系统。无论是开发测量工具、集成硬件外设，还是从源代码编译 OS，都可以在这里找到按开发任务组织的完整指南。

**本节内容：**

* **简介** — 了解 Red Pitaya 软件架构、开发方式和工作流程
* **入门** — 通过 SSH 或串口连接建立控制台访问
* **应用程序开发** — 使用 C++/Python API、流式传输和 Web 界面构建应用程序
* **系统开发** — 编译 OS 生态系统、创建 Debian 软件包并构建自定义镜像
* **配置与集成** — 配置网络、GPIO、SPI、显示设备和远程部署
* **安全注意事项** — 用户账户、权限和安全部署实践
* **故障排除** — 已知软件问题及规避方法
