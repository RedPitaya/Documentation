.. _sw_configuration:

##################################
系统配置与集成
##################################

本节介绍如何配置 Red Pitaya 操作系统并与外部硬件外设集成，包括网络设置、GPIO 控制、通信接口和远程部署指南。

**本节内容：**

* **网络配置** — 设置 Wi-Fi、以太网和自定义网络配置
* **服务管理** — 控制系统服务（Web 界面、SCPI 服务器等）
* **GPIO 控制** — 从软件访问并控制数字 I/O 引脚
* **SPI 接口** — 使用 SPI 通信接口连接外设
* **TFT 显示屏** — 连接并配置 TFT 显示屏
* **远程部署** — 自动完成软件部署和更新
