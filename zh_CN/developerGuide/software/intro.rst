##################################################
Red Pitaya 软件开发简介
##################################################

1. 理解 Red Pitaya 软件架构
==================================================

Red Pitaya 在 ARM Cortex-A9 处理器上运行完整的 Linux 操作系统（基于 Debian）。软件栈包括：

* **Linux 内核** — 包含用于 FPGA 通信和外设的自定义驱动程序的修改版内核
* **系统库** — 标准 Linux 库和 Red Pitaya 专用 API
* **应用程序** — Web 应用程序、命令行工具和后台服务
* **FPGA 接口** — 用于与 FPGA 硬件通信的驱动程序和 API

此架构使你能够：

* 开发标准 Linux 应用程序
* 创建自定义 API 和驱动程序
* 构建基于 Web 的用户界面
* 与现有 Linux 工具和框架集成

|

2. 开发方式
==========================

应用程序开发
-----------------------

使用所提供的 API 开发在 Red Pitaya 上运行的应用程序：

* **C++ API** — 原生性能，直接访问硬件
* **Python API** — 快速制作原型，开发更简便
* **Web 应用程序** — 基于浏览器的用户界面
* **流式传输应用程序** — 向 PC 高速传输数据

**最适合：** 创建自定义测量工具、自动化脚本和数据采集应用程序

系统开发
------------------

修改或重新构建 Red Pitaya 操作系统和生态系统：

* **生态系统构建** — 从源代码编译整个 Red Pitaya OS
* **Debian 软件包** — 创建可安装的软件包
* **自定义镜像** — 构建用于部署的修改版 OS 镜像

**最适合：** 自定义 OS 配置、系统集成和生产部署

配置与集成
---------------------------

配置并扩展 Red Pitaya 的能力：

* **网络配置** — Wi-Fi、以太网和自定义网络设置
* **外设集成** — GPIO、SPI 和 I2C 接口
* **硬件附件** — TFT 显示屏和自定义硬件
* **远程部署** — 自动化软件更新和管理

**最适合：** 系统管理、硬件集成和部署自动化

|

3. 开发工作流程
========================

典型应用程序开发
--------------------------------

1. **访问 Red Pitaya** — 通过 SSH 或串口控制台连接
2. **选择 API** — 注重性能选择 C++，注重易用性选择 Python
3. **开发与测试** — 编写代码并在设备上测试
4. **部署** — 复制到 Red Pitaya 或构建为软件包

典型系统开发
---------------------------

1. **设置构建环境** — 克隆仓库并安装依赖项
2. **修改组件** — 更改生态系统、应用程序或内核
3. **构建** — 编译修改后的组件
4. **测试** — 部署到 Red Pitaya 并验证
5. **打包** — 创建 Debian 软件包或 SD 卡镜像

|

4. 前提知识
=================

**应用程序开发：**

* 基本 Linux 命令行知识
* 编程经验（C、C++ 或 Python）
* 理解信号处理概念
* 用于远程访问的 SSH 客户端

**系统开发：**

* 高级 Linux 知识
* 构建系统（Make、CMake）使用经验
* 理解 Debian 软件包管理
* 具备交叉编译经验会有所帮助
