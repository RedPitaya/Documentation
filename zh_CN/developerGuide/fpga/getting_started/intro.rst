###########################################
Red Pitaya FPGA 开发简介
###########################################

了解 Red Pitaya 架构
==========================================

Red Pitaya 软件由协同工作的两大部分组成：

1. **FPGA Image** - 运行在 Xilinx Zynq FPGA 上的硬件逻辑，负责高速信号处理、数据采集和信号生成（也称为可编程逻辑（PL）侧）
2. **Linux Operating System** - 运行在 ARM 处理器上的软件，并通过驱动与 FPGA 交互（也称为处理系统（PS）侧）

FPGA 与 ARM 处理器集成在同一颗 Xilinx Zynq 片上系统（SoC）中，从而实现硬件与软件组件之间的无缝通信。

|

所需开发工具
===========================

针对 Red Pitaya 进行 FPGA 开发需要使用特定版本的 Xilinx 工具：

AMD (Xilinx) Vivado（版本取决于 OS）
--------------------------------------------

**工具简介：** Vivado 是用于创建和修改 FPGA 设计的主要开发环境，其中包括：

* 用于编写 Verilog/VHDL 代码的 HDL 编辑器
* 用于图形化设计的框图编辑器
* 综合与实现工具
* 仿真环境
* 比特流生成

**使用时机：** 任何 FPGA 开发工作都必须使用 Vivado。

**当前版本对应关系：**

* **OS 3.00 或更高版本：** Vivado 2025.1
* **OS 1.04 - 2.00：** Vivado 2020.1

AMD Vitis 2025.1（当前）/ Xilinx SDK 2019.1（旧版）
-----------------------------------------------------------

**工具简介：** Vitis（当前版本）和 SDK（旧版）用于开发运行在 ARM 处理器上的应用程序，并与 FPGA 设计进行交互。

**使用时机：** 仅当需要修改 ARM 侧软件（驱动、API、自定义应用、FSBL/设备树相关流程）时才需要。如果只修改 FPGA 逻辑并使用现有软件，通常不需要 Vitis/SDK。

**当前版本对应关系：**

* **OS 3.00 或更高版本：** Vitis 2025.1（在当前安装流程中与 Vivado 一起安装）
* **OS 1.04 - 2.00：** SDK 2019.1（保留旧版页面以实现向后兼容）

|

你可以完成的工作
========================

根据项目目标，你可以进行以下工作：

**仅修改 FPGA 设计**

* 修改信号处理算法
* 添加新的硬件外设
* 修改时序和数据通路
* 定制现有的 Red Pitaya 项目
* **所需工具：** 仅需 Vivado

**仅修改 ARM 软件**

* 修改应用逻辑
* 添加新的软件功能
* 修改 API 和驱动
* **所需工具：** Vitis（当前流程）或 SDK（旧版流程），并使用现有 FPGA 比特流

**完整的定制开发**

* 创建全新的 FPGA 设计
* 开发配套的软件驱动
* 集成定制硬件外设
* **所需工具：** Vivado + Vitis（当前流程）或 Vivado + SDK（旧版流程）

|

开发工作流概览
==============================

典型的 FPGA 开发工作流包含以下步骤：

1. **设置环境** - 安装 Vivado，以及（如有需要）Vitis（当前版本）或 SDK（旧版）
2. **创建/修改项目** - 从现有项目开始，或创建新项目
3. **设计** - 编写 HDL 代码或修改框图
4. **仿真** - 使用行为仿真验证逻辑（关键步骤！）
5. **综合** - 将 HDL 转换为硬件门电路
6. **实现** - 在 FPGA 上进行布局布线
7. **生成比特流** - 创建 FPGA 二进制文件
8. **硬件测试** - 加载到 Red Pitaya 并进行验证
9. **集成软件** - 创建/更新驱动和应用程序（如有需要）
