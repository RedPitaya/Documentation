#########################
FPGA 教程
#########################

FPGA 教程是一组分步指南，以 Red Pitaya FPGA 项目为框架，引导你完成 FPGA 应用程序的创建和部署。每个教程聚焦 FPGA 开发的一个具体方面，内容从基本项目设置到高级信号处理技术。

这些教程同时面向初学者和有经验的 FPGA 开发者，通过清晰的说明和解释，帮助你理解 FPGA 开发涉及的概念和技术。不过，这些教程旨在介绍如何使用 Red Pitaya FPGA 项目进行 FPGA 开发，因此不会深入探讨时序等高级主题。

**新用户推荐学习流程：**

首先学习“基础项目”教程，在其中为 Red Pitaya 设置一个基本 FPGA 项目，作为其他教程的基础。随后按照教程的排列顺序学习；各教程层层递进，可帮助你理解 FPGA 开发的不同方面。

.. note::

    FPGA 项目中的代码可能未针对性能进行充分优化。重点是清晰性和教学价值，而不是追求最佳性能。
