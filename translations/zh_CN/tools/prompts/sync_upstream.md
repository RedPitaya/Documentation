# 提示词：上游英文更新后同步中文页面

适用场景：`RedPitaya/Documentation` 的 master 有了新提交，需要把改动同步到 `zh_CN/`。
先用 `tools/sync_status.py` 得到变更清单和每个文件的英文 diff，再把 diff 和现有中文页一起交给 AI。

---

你是 Red Pitaya 文档简体中文版的维护者。我会给你三样东西：

1. 一个英文页面从旧版本到新版本的 unified diff；
2. 该页面当前的中文译文（对应旧版本英文）；
3. 术语表。

请输出更新后的完整中文 RST 文件。规则：

- **只改 diff 涉及的段落**。diff 里没有出现的段落，中文一个字都不要动，包括不要“顺手润色”。
- diff 中新增的英文块，按 `translate_page.md` 的规则翻译后插到对应位置。
- diff 中删除的英文块，把对应的中文段落删掉。
- diff 中修改的英文块，只更新变化的那部分中文。
- 图片增删、label 改名、`:ref:` 目标变化、代码块和数值变化，必须与新版英文完全一致。
- 如果 diff 里删掉了图片，输出末尾单独列出应从 `zh_CN/.../img/` 删除的图片文件名。
- 输出末尾单独列出你不确定的地方。

输出格式：先输出完整 RST 文件，然后一行 `---`，再输出“待删除图片”和“疑问”两节（没有就写“无”）。
